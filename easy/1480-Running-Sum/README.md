# LeetCode 1480 - Running Sum of 1D Array

## Problem Description
Given an integer array nums, return the running sum of the array.

## Approach
We use a for loop to calculate the running sum.

A variable named sum stores the total of previous elements. At each iteration, we add the current element and store the result in a new array.

## Example

Input: [1, 2, 3, 4]

Output: [1, 3, 6, 10]

## Complexity Analysis
- Time Complexity: O(n)
- Space Complexity: O(n)
